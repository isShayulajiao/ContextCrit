ScopeCrit 环境配置与常用命令

1. 安装
需要 Python 3.11 或以上；API 模式无需 GPU、CUDA、PyTorch 或本地模型权重。
先进入 CultCrit-Bench/ScopeCrit 目录：
conda create -n scopecrit python=3.11 -y
conda activate scopecrit
python -m pip install -r requirements-lock.txt
python -m pip install --no-deps -e .
直接运行 run.py 不需要安装项目；editable 安装保证从其他目录运行包及测试也可用。

2. 本地配置
复制 settings.example.yaml 为 settings.local.yaml，只在复制文件中填真实 Key。
Windows 可手动复制，或：Copy-Item settings.example.yaml settings.local.yaml
主要字段：
inputs：一个或多个数据文件绝对路径，各文件都是 JSON 数组。
agent_config：configs/deepseek.yaml，默认仍由 deepseek-flash 决策。
actor_workers：4 表示最多同时答题 4 条样本；命令行 --workers 4 可覆盖，范围 1–32。
api_keys.deepseek：DeepSeek Key。
api_keys.qwen：阿里云百炼 Key。
api_keys.minimax / api_keys.gemini：APIKEY.FAN Key，可相同，但需各自模型权限。
qwen_workspace_id：北京业务空间 ID，不能用地域名或 API Key 替代。
max_samples：null 为全部，4 为每文件原始顺序前 4 条任务。
run_dir：null 自动生成；多文件时可填输出根目录。
judges_config：configs/judges.yaml。
configs/judges.yaml 顶层 workers: 3 表示三位裁判同时评分，各裁判内部逐样本执行。
inputs 与旧版单文件 input 只能填一个。Windows 路径使用单引号，例如：
inputs:
  - 'F:\dataset\test.json'
  - 'F:\dataset\another.json'
Qwen 可改填完整 qwen_base_url，此时 qwen_workspace_id 留空。
北京地址：https://你的WorkspaceId.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
minimax_base_url 和 gemini_base_url 默认：https://api.apikey.fan/v1
无需 export 或手动设置环境变量；SDK 认证由程序内部处理。
settings.local.yaml 已加入 Git 忽略，不把真实 Key 填进公开模板或源码。

3. 常用命令
先处理每个文件前 4 条：
python run.py --settings settings.local.yaml --max-samples 4
并发答题（先完成本文件答题，再并发评分）：
python run.py --settings settings.local.yaml --max-samples 20 --workers 4 --run-dir runs/parallel_001
处理每个文件全部任务：
python run.py --settings settings.local.yaml --max-samples None
只答题，暂不调用裁判：
python run.py --settings settings.local.yaml --max-samples 4 --no-judge
指定输出位置；多文件时为输出根目录：
python run.py --settings settings.local.yaml --max-samples 4 --run-dir runs/trial_001
已有答案只评分：
python run.py --settings settings.local.yaml --evaluate-only --run-dir runs/trial_001
恢复已有答题运行：
python run.py --settings settings.local.yaml --resume --run-dir runs/trial_001
恢复可指向单个运行目录或多文件根目录。使用原输入、配置、选中范围，不以续跑扩大旧实验。
不确定历史请求默认暂停。重试答题显式加 --retry-uncertain；重试裁判加 --retry-uncertain-judges，可能重复计费。

4. 模型与结果
答题模型：deepseek-flash。
三个独立评分裁判：qwen3.8-flash、minimax-m3.1-flash、gemini-3.1-flash-lite。
模型名原样发送，不静默替换；旧四裁判组合不再是默认配置。
各文件独立输出，主要看 judge_summary.json、metrics_summary.csv、per_sample_metrics.csv、report.md。
正式均值要求三位裁判对该指标均完整评分；缺失为 null，另列可用均值和有效裁判数。

5. 可选本地小模型
agent_config 可指向自定义配置，以 kind: openai 接入本地 OpenAI 兼容服务。
本机示例：http://127.0.0.1:8000/v1，模型 ID Qwen/Qwen3-1.7B，api_key_env: null。
关闭思考：extra_body.chat_template_kwargs.enable_thinking: false，需服务端支持。
也可仅覆盖 stage_providers.ACTION，其他阶段仍用 DeepSeek，须报告为混合模型实验。
远端自定义答题 Key 填 api_keys.actor，provider 使用内部字段 api_key_env: SCOPECRIT_ACTOR_API_KEY。
详细 YAML 见 README。项目不负责启动推理服务、下载模型或训练。
