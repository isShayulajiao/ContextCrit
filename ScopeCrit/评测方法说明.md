# 自动评测方法说明

本系统采用多模型独立语义对齐与确定性指标计算相结合的评测流程。被测 Agent 完成任务后，DeepSeek-Flash、GLM-4.5-Air、Qwen3.8-Flash 和 Grok-Build-0.1 分别作为独立裁判，依据统一规则比较预测主张与标准主张，在命题内容、评价对象、范围、阶段、条件、声音归属及不确定性一致的前提下建立一对一等价配对。裁判之间不共享评分结果，标准答案仅进入离线评测阶段，不向答题 Agent 反馈。程序基于各裁判的对齐结果分别计算主张覆盖率、方面与立场 F1 以及记忆 F1；T2 额外评价跨证据关系解释，T3 分别评价各轮累计记忆，T4 判断答案是否实质依赖双方资料。证据集合、实际消息投递和访问权限等可确定性核验的指标由程序统一计算。对四个裁判分别计算得到的相同语义指标取算术平均，并报告各裁判结果、标准差及评分覆盖情况。请求失败、无法判断或不完整对齐不记为零分；仅当全部预定裁判对相应指标完成有效评分时给出正式均值。该流程属于模型自动评测，不等同于人工金标准。

可选综合分的权重和定义单独记录：T1 为方面 Micro-F1、立场 Macro-F1 与证据 F1 等权平均；T2 为主张 Micro-F1、关系解释质量和证据 F1 等权平均；T3 为全部预期轮次 Memory F1 的平均；T4 为语义 Task Success rate。关系解释质量采用预先规定的 correct=1、partial=0.5、incorrect=0 映射，未评分保持缺失。四任务综合分均有效时，按等权宏平均给出整体分数。False Overwrite、交换召回率、权限错误与资源消耗单独报告。综合分为本系统的展示性约定，不替代各项原始指标。

使用说明：以上描述的是已经实现的程序流程。本次验收使用本地 HTTP 模拟验证四家 SDK 及指标计算，没有运行真实付费模型实验。论文如报告实际结果，应记录真实使用的模型 ID、接口、时间、参数、评分完成率及裁判分歧，不能把模拟测试结果作为模型性能。
