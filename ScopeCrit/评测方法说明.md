# ScopeCrit 自动评测方法说明

## 评分与答题隔离

答题 Agent 默认由 `deepseek-flash` 完成 T1–T4。预测持久化后，三个独立裁判 `qwen3.8-flash`、`minimax-m3.1-flash`、`gemini-3.1-flash-lite` 读取预测和 gold；前者使用百炼北京业务空间接口，后两者使用 APIKEY.FAN OpenAI 兼容接口。Gold 不进入答题阶段，裁判结果不反馈给正在执行的 Agent，各裁判不共享其他裁判结果。

本流程扩展原方案的独立语义对齐入口。无语义对齐时，程序不能用相同 ID、词重叠或参考答案字符串相等替代语义判断。`--no-judge` 只生成预测及程序可核验指标。

## 一对一主张对齐

设预测集合为 P，标准集合为 G，一对一内容等价匹配为 A。裁判依据命题、对象、范围、阶段、条件、不同声音和不确定性判断等价。Aspect、stance、证据相同不作为配对前提，否则后续标签指标会形成循环定义。同义重复预测只能匹配一次，多报可产生假阳性。

T3 各轮分别对齐累计记忆，保留最终轮结果。非空预测缺完整对齐时保持未评分，不能把未列出的预测默认判错。无预测的真实失败可以按零覆盖处理。超时、拒答和预算耗尽不从总数中删除，同时报告状态及语义评分覆盖率。

## 原始指标

| 指标 | 定义与边界 |
|---|---|
| T1 Aspect Micro-F1 | TP 为等价匹配且方面相同的对数；FP=\|P\|−TP，FN=\|G\|−TP；F1=2TP/(2TP+FP+FN) |
| T1 Stance Macro-F1 | 对四种固定立场分别计算 F1 后宏平均；错分计预测类 FP 和标准类 FN；无分母类别 null，报告参与类别数 |
| Evidence F1 | 预测证据并集与 required_evidence_ids 的集合 F1；ID 正确不等于语义支持正确 |
| T2 Claim Coverage | 已匹配标准主张数 / 标准主张总数 |
| T2 Claim Micro-F1 | 根据主张一对一匹配计算 F1，包含多报惩罚 |
| T2 关系解释质量 | correct、partial、incorrect、unscored 映射为 1、0.5、0、null |
| T3 Memory State F1 | 第 t 轮为 2TP_t/(\|P_t\|+\|G_t\|)，报告逐轮与最终轮 |
| T3 False Overwrite | 分母为前轮正确记住且本轮仍成立的机会数，分子为其中本轮丢失数；分母零时 null |
| T4 Expected Exchange Recall | 对预期 (from,to,evidence_id)，统计合法、准确且实际投递的方向性证据覆盖；重复不增加覆盖 |
| T4 Task Success | 必要主张覆盖、必要证据引用、权限合法、答案实质依赖双方材料；语义项未评分时 null |

证据集合、实际消息投递和权限由程序计算；关系解释和双方实质依赖需要语义判断。额外合理交换不在预期清单中，不因此直接视为有害。不计算 Attribution Accuracy。

越权尝试、实际越权交付、引用真实但未公开的未来/私有证据、引用不存在 ID 分别统计。总体权限诊断不覆盖整批原始质量均值，T4 成功条件仍包含合法访问。

## 三裁判汇总与缺失值

每位裁判先独立对齐并计算指标，再对相同指标取算术平均；不先投票配对或平均标签。各项报告裁判分值、正式 mean、诊断性 available_mean、有效/预定裁判数、标准差、最小值与最大值。

正式均值要求三位裁判对该指标所需目标全部完整有效评分。失败、无法判断或不完整覆盖保持 null；只有两位完成时可以显示两位 available_mean，不能称为三裁判正式均值。无分母指标也可能 null，应结合原始计数及完成状态区分。程序指标只计算一次，不对相同结果重复投票。

## 可选综合分

以下是额外约定的展示指标，原方案的原始指标仍保留。质量分数沿用 0–1 尺度，不按当前实验做 min–max 归一化。

| 综合分 | 定义 |
|---|---|
| T1 | Aspect Micro-F1、Stance Macro-F1、Evidence F1 等权平均 |
| T2 | Claim Micro-F1、关系解释质量、Evidence F1 等权平均 |
| T3 | 全部预期轮次 Memory State F1 平均，另报最终轮 |
| T4 | 语义 Task Success rate，避免重复计算组成条件 |
| 整体 | 四任务综合分等权宏平均，四项均有效才给正式整体分 |

先为每位裁判构造任务分，再汇总三裁判；组成项缺失不重新分配权重。False Overwrite、交换召回、权限错误、调用数、token、费用、耗时单列，不重复混入综合分。只运行部分任务时已有任务可查看，正式整体分可能 null。

## 实验报告要求

多输入文件分别运行和出表，条数上限按每文件原始任务顺序生效。比较答题模型时，保持相同输入范围、可见材料、提示词、预算、评分模型与评分规则，保留配置和实际用量。只有 ACTION 用小模型、支持核对或范围比较用 DeepSeek 时，明确标为混合配置。

模型自动评测不等于人工金标准。本地测试与 HTTP 模拟验证流程，不构成真实文学能力实验。真实实验应记录实际模型 ID、接口、调用日期、参数、评分完成率、裁判分歧；不能把模拟分数或缺失裁判后的可用均值当作完整实验结果。
